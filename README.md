# Training Navigator

A dependency-free local media-browser reference for Windows. It opens local fixed disks and loads one folder at a time, so browsing remains fast with large collections.

## What it does

- Starts with clear drive cards and a direct Training Library shortcut.
- Opens folders on demand with breadcrumbs, Back, Refresh, folder filtering, and kind-first sorting.
- Plays supported video and audio files; previews images, PDFs, text, and browser-readable files.
- Saves video position on the local server.
- Keeps hidden, system, and the app's own data/publishing folders out of the browser.

## Run locally

For a one-off local session, run `./start-training-library.ps1` and open `http://localhost:8797`.

Deployment, remote-access, media-path, and user-data configuration are intentionally excluded from this public source mirror.
